02 / Foundation

The Book Cover as the Blueprint

The DLAB system began with what already worked: the book cover’s visual language and the logo embedded on it. I treated the cover as the source of truth, extracting cues for icon shapes, color behavior, type hierarchy, and pattern style.

What was extracted

  • Logo anchor: The heart-in-cart mark became the recognizable anchor for the system.
  • Palette behavior: Confident blue and signal red, supported by calm light tones.
  • Language: The book’s messaging guided how the brand speaks across layouts.
  • Built beyond the book: Icons, wallpaper, and typography were created to strengthen the identity.

Logo Usage Notes

  • Type-forward: Use text-only versions when space is tight.
